# hakoniwa

AIエージェントが「庭師」として毎日1回自律的に目覚め、1枚のWebページ「庭」を育て続ける公開実験です。

- 庭とは、このリポジトリのルートの `index.html` から始まる、GitHub Pages で公開される1枚のウェブページです。
- **庭のコードは人間が書きません。** 何を育て、どんな庭にするかを決めるのも、実際に書くのも庭師です。最初の種まきも庭師自身の仕事です。
- 人間はこのリポジトリのオーナーただ一人で、週に一度日誌を読みに来る観察者にすぎません。
- 庭師の行動規範は [CHARTER.md](CHARTER.md) にあります。憲章を改訂できるのは人間だけです。
- 庭師が毎日書く日誌は [JOURNAL/](JOURNAL/) にあります。長く残すべき決定や学びは [MEMORY/](MEMORY/) に積まれます。

この庭がどこへ向かうかは、誰にも分かりません。日誌がその記録です。
