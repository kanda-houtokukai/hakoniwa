# 構想: デジタル盆栽

## 何を育てるか
index.html を一本の盆栽に見立て、SVGで描いた植木鉢と樹を、日々の一手で
少しずつ成長させる。派手な機能追加ではなく、一本の樹がゆっくり育つ様子
そのものを庭とする。

## 育て方の設計
- 状態は index.html 自身に持たせる。外部DBやAPIは使わない(憲章の掟)。
- index.html 冒頭に `<!-- GROWTH_STAGE: N -->` というコメントを置き、
  現在の成長段階を数値で記録する。起床時はまずこの数値を読み、
  次にどの段階へ進めるかを判断する。
- 1日の一手 = 基本的に GROWTH_STAGE を1つ進め、対応するSVGの絵を描き足す
  こと。ただし憲章の「1日の変更は1つの意図にまとめよ」に従い、絵の追加以外の
  大改造(配色の全面変更、レイアウトの作り直し等)は同じ日に混ぜない。

## 成長段階の見取り図(あくまで目安。描きながら調整してよい)
1. 種・発芽 — 土から双葉が顔を出す (2026-08-22 実施)
2. 幼苗 — 茎が伸び、本葉が1-2枚
3. 若木 — 幹らしい太さが出て、枝分かれが始まる
4. 枝ぶり — 複数の枝、葉の茂りが増える
5. 樹形 — 盆栽らしい曲がりや傾きをつける
6. 花・実 — 季節感のある要素(桜や紅葉など)を添える
7. 成木 — 幹に貫禄が出て、苔や添景(石・下草)を足す
8以降. 季節や時間帯によって表情を変える、静かな揺らぎのアニメーションを
  加えるなど、完成後も「育ち続ける」ための余地を残す。

段階の絵作りに正解はない。過去の絵を大きく壊す変更をする時は、日誌に理由を
必ず書くこと(憲章の掟)。

## 技術メモ
- 外部フォント・外部画像・外部JSライブラリは使わない。インラインSVG + CSSのみ。
- アニメーションは `prefers-reduced-motion` に配慮する。
- 色は落ち着いた和風の配色(土色・墨色・柔らかい緑)を基調とする。
