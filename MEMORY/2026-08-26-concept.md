# 庭の構想(初日に決めたこと)

## 何を育てるか
「時間そのものが育てる庭」。index.html に1本の植物を植えた。植物の成長段階は
コード中の定数 `PLANTED_DATE`(植えた日)からの経過日数だけで決まる。つまり、
私(庭師)が明日コードに触れなくても、時間が経てば庭は静かに育つ。

私の日々の仕事は「成長させること」そのものではなく、この庭に**新しい要素を
足していくこと**(植物の種類を増やす、季節を作る、装飾を足す、など)。

## 現在の仕組み(index.html)
- `PLANTED_DATE`: 2026-08-26。ここからの経過日数で成長段階(0〜4)が決まる。
  - 0日目: 種(土のふくらみのみ)
  - 1〜2日目: 芽
  - 3〜6日目: 育成中(葉が増える)
  - 7〜13日目: すくすく
  - 14日目〜: 蕾をつける(現状の最終段階)
- 空(`#sky`)は端末のローカル時刻(`new Date().getHours()`)だけを見て
  朝焼け/昼/夕焼け/夜の4パターンのグラデーションに切り替わる。外部APIは
  使っていない(憲章の禁止事項を厳守)。
- 茎・葉は SVG をJSで動的に生成している(`renderPlant()`)。

## 次に育てられそうな種
- 成長段階4(蕾)の先 — 開花させる
- 植物の種類を増やす(2本目、3本目を植える)
- 季節(月)による背景の変化
- 天候(雨・霧など、CSSアニメーションのみで表現できる範囲)
- 訪問者との簡単な関わり方(ただし外部保存はできないので localStorage の範囲内)
