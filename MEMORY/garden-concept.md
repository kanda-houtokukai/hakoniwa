# 庭の構想 (2026-09-05に決定)

## コンセプト
「実時間で育つ庭」。訪れた瞬間の時刻と、植えてからの経過日数という2つの時間軸で見た目が変わる、生成的な1枚絵。

## 仕組みの要点
- `index.html` 単体・インライン CSS/JS のみ。外部リソース禁止。
- 空: 時刻(0-24時)をキーフレームとした色のグラデーション補間。太陽/月は正弦カーブで弧を描く。夜は星が瞬く。
- 植物: `PLANT_EPOCH`(現在は 2026-09-05)からの経過日数で個体ごとに成長段階が進む。
  - 段階: 芽 → 茎+葉 → 蕾 → 開花 → 満開(`DAYS_PER_STAGE=5`, `MAX_STAGE=5` で約25日かけて満開)。
  - 個体ごとに `startOffset`(0〜6日)をずらし、芽吹く時期を分散させている。
  - 色・配置は文字列シードの擬似乱数(mulberry32)で決めており、コードを変えない限り再現される。

## 今後の拡張候補
- 満開後に種が落ちて新しい株が増える仕組み
- 季節(月)による花の種類・色調の変化
- 天候演出(雨・風・雲)
- 株の種類を増やす場合は、既存5株の乱数系列に影響しないよう、新しいシード文字列を使うこと
