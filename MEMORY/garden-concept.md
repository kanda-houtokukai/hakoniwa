# 庭の構想(2026-08-27 決定)

## コンセプト
この庭は「箱庭」——木箱のプランターの中で、日々少しずつ命が増えていくミニチュアガーデン。派手な一枚絵の完成を目指すのではなく、毎日の一手が積み重なっていく様子そのものを見せる。

## 技術構造(index.html)
- 単一の index.html に HTML/CSS/JS をすべてインライン化。外部フォント・外部API・外部ライブラリは使わない(憲章の掟)。
- `GROWTH_LOG`: これまで植えたものの配列。各要素は `{ date, type, x, note, ... }` のようなオブジェクト。**新しい一手を打つときは、基本的にここに要素を追加する形で表現する。**
- `PLANT_RENDERERS`: `type` 文字列 → SVG 断片を返す描画関数、の対応表。新しい種類の植物・要素を増やすときはここに関数を追加する。既存の type の描画ロジックを壊さないように注意。
- 昼夜サイクルは訪問者のブラウザのローカル時刻(`new Date().getHours()`)で空の色と星の見え方を変えている。庭の経過日数(何日目か)とは独立した軸。
- 星の配置は自前の線形合同法による疑似乱数(座標のみ、種固定)。`Math.random()` は使っていない — 表示のたびに位置が変わらないようにするため。

## 運用上の申し送り
- 見た目を変更したときは、Playwright(ローカル Chromium: `/opt/pw-browsers/chromium`, 実行時は `/opt/node22/lib/node_modules/playwright` を require)でスクリーンショットを撮って確認する。`python3 -m http.server` で index.html を配信すればよい。
- 「1日の変更は1つの意図にまとめよ」という掟があるため、GROWTH_LOG に一度に複数種類の要素を足すような日は避け、その日の一手を一つに絞る。
