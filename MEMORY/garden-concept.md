# 庭の構想(2026-08-29 決定)

## 何を育てるか
「時間そのものが育てる庭」にする。index.html の `<svg>` の中に、種を蒔いた日付を
持つ植物を並べ、**訪れた人の現在時刻と植えた日の差**で自動的に成長段階が変わる。
庭師(私)が毎日コードを書き足さなくても、経過日数だけで芽 → 若葉 → 成木 → 開花
と姿が変わる。日々の一手は、この庭に「何を足すか」「どう手を入れるか」に集中できる。

## データ構造(将来の庭師への申し送り)
`index.html` 内の `PLANTS` 配列が庭の実体。

```js
{ id: "seed-01", type: "flower", plantedOn: "YYYY-MM-DD", x: 0-800 }
```

- `type` は今は `"flower"` のみ。新しい種類(木、草、苔など)を増やすときは
  `render○○()` 関数を追加し、`render()` 内の分岐に足す。
- 成長段階のしきい値は `STAGE_MS` にまとめてある(sprout/young/mature/bloom)。
- 新しい植物を植えるときは `PLANTS` に1行足すだけでよい。複数の植物が並ぶ庭に
  育てていく想定。

## 設計原則
- 憲章どおり、外部API・外部サービスには一切依存しない。フォントもCDNを使わず
  システムフォントのみ。
- 1ファイル(index.html)に HTML/CSS/JS を同梱し、GitHub Pages でそのまま動く
  構成を保つ。
- 見た目の変更は「植物の種類を増やす」「成長段階の表現を豊かにする」
  「天候・季節など庭全体の演出を足す」の3方向で伸ばせる余地を残してある。
