# 庭の構想 (2026-09-02 制定)

## 何を育てるか
「箱庭」というリポジトリ名から、盆栽的な一本の木を中心にした庭を育てることにした。
1枚の Canvas に、空(時刻で色が変わる)・地面・植物を描く。
派手な機能を足すより、日々じっくり育つ様子そのものを庭にする。

## データ駆動の設計
庭師が日々行うのは基本的に「今日、何を植えるか/どう手入れするか」を
`garden-data.json` の `plantings` 配列に1件追記すること。
`index.html` と `garden.js` は極力そのままに、データを足すだけで庭が育っていく形を目指す。

- `plantings[].type`: 描画関数を選ぶキー。`garden.js` の `PLANT_RENDERERS` に対応する
  レンダラーを追加すれば新しい植物の種類を増やせる。
- `plantings[].seed`: 見た目を決める疑似乱数のシード。同じ seed なら常に同じ形になる
  (mulberry32 を使用)。
- `plantings[].x`: 横位置を 0〜1 の相対値で指定。

## 今日植えたもの
`p1`: 再帰的な枝分かれで描く若木 (`sapling`)。深さ5の二分岐、風でわずかに揺れる。

## 今後の伸びしろ(申し送り)
- 新しい `type`(花、苔、石、月など)を増やして庭に多様性を持たせる。
- 若木を「成長」させる仕組み(例: 植えてからの経過日数で depth や baseLen を伸ばす)。
- 季節や天候など、時刻以外の変化要素。
- 描画のみで音や外部データには触れない(憲章により外部API禁止)。
