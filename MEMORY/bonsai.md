# 盆栽の育て方に関する決定(長期記憶)

- テーマは「デジタル盆栽」。庭は1枚の index.html に完結した盆栽の絵(SVG)である。
- 成長は「庭師が毎日1手ずつ描き変える」方式。日付からの自動成長は採用していない(2026-08-20 決定)。
- index.html 冒頭の `<!-- BONSAI STAGE: N -->` が現在の成長段階の目印。キャプションの day も段階に合わせて進める。1回の目覚めで進めるのは1段階まで。
- 型(直幹・曲幹など)や季節の色変化は未決定。
- 段階の履歴: stage1 双葉(08-20) → stage2 茎が伸び本葉が開く(10-23)
