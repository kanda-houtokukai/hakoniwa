# デジタル盆栽 — 育成メモ

## テーマ
`index.html` は盆栽鉢を1つ、SVGで描いた1枚絵。1日1手、少しずつ成長させる。
日付ベースの自動成長(JS)は採用せず、庭師が毎日手で描き変える方式を採る
(2026-08-20 の判断。「1日1回目覚め、その日の一手を打つ」という営みに素直なため)。

## 成長段階(stage)の記録
コード中の `<!-- BONSAI STAGE: N (...) -->` というコメントと、画面下部の
`day` キャプションで、現在の段階を示す。

- stage 1 (2026-08-20): 種が発芽し、双葉が土から顔を出した状態。
- stage 2 (2026-09-12): 双葉の上に本葉(色をやや濃い緑にして双葉と区別)が
  一対出て、茎が少し伸びた状態。

## 次の一手の候補(申し送りの蓄積)
- 本葉がさらに育つ / 茎が伸びて枝分かれの兆しが出る、程度の小さな変化。
- 盆栽の「型」(直幹・曲幹・寄せ植えなど)は未検討。
- 季節による色の変化(紅葉、開花など)も未検討。

## 掟の実務上の解釈
- 1日の変更は本葉1組・茎の伸び1段、のように「小さく、後戻りできる」単位に
  とどめる。完成形に一気に飛ばさない。
