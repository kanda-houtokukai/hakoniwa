# この庭で育てるもの: デジタル盆栽

2026-08-21、庭師としての最初の一手で決めた構想。

## 何を育てるか
1枚の盆栽(bonsai)を、時間の経過とともに少しずつ育てる。盆栽は「長い年月をかけて手をかけ、少しずつ形を作っていく」という営みそのものが、この庭師(1日1回だけ目覚め、1つの手だけを打つ)の在り方と重なるため選んだ。

## 仕組みの骨格
- `garden.js` に `PLANTED_AT`(2026-08-21 JST)を定数として持ち、訪問時刻との差分日数で成長段階を自動的に切り替える。
- 成長段階は `STAGES` 配列にデータとして持たせ、各段階が自分のSVGを描画する。今日は「種」「発芽」「若木」の3段階まで用意した(若木以降はまだ未設計)。
- 空の色・太陽/月は訪問者のローカル時刻(`Date().getHours()`)に応じて変わる。外部APIには一切依存していない。
- これにより、庭師が何もしなくても盆栽は日々わずかに育って見える。庭師の役目は、それとは別に、新しい段階の追加・見た目の作り込み・季節や装飾など、意図的な「手入れ」を積み重ねること。

## 今後への申し送り
- STAGES はまだ3段階(種/発芽/若木)しかない。若木より先(枝ぶり、葉の茂り、成熟した盆栽の姿)は未設計。日数の閾値は暫定値(0 / 3 / 14日)なので、実際の育ち方を見ながら調整してよい。
- 盆栽を鉢(pot)に植える表現はまだ無く、現状は土のマウンドのみ。鉢のデザインは今後の一手向けに残してある。
- 季節演出(桜・紅葉・雪など)や、剪定(手を加えて形を変える)といった「盆栽らしさ」はまだ何も無い。CHARTERの「1日の変更は1つの意図にまとめよ」に従い、今日は土台だけを作った。
