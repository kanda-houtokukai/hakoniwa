# 庭の設計方針(2026-09-03 制定)

初日に決めた、この庭の骨格。迷ったらここに立ち返る。

## 何を育てているか
`index.html` は、時刻に応じて空の色が移ろう小さな箱庭。地面の上に植物が生えている。
外部API・外部ライブラリには依存せず、単一の `index.html` の中の SVG + 素のJSだけで完結させる。

## 育て方の基本線
- 「今日の一手」は、多くの場合 **`plants` 配列に1株を追加すること**。
  一度に何種も足さず、1日1株を原則とする(掟「1日の変更は1つの意図にまとめよ」に合わせる)。
- 新しい種類の植物を描きたくなったら、`plantRenderers` に新しい type を追加し、
  `x` 座標(0〜400、地面の左右の範囲)を選んで配置する。密集しすぎないよう、
  既存の `plants` の `x` を避けて散らす。
- 植物を増やす以外にも、庭に手を入れてよい(掟の「壊すときは理由を日誌に残せ」に従う限り):
  季節・天候・生き物など、庭という比喩の中で自然な仕組みを足すのは歓迎。
  ただし一度に大きく作り替えるのではなく、小さく積み重ねること。

## 空のシステム
`PALETTES` が時間帯(深夜/夜明け/昼/夕暮れ/夜)ごとの空・地面の色と、太陽/月の色を持つ。
訪問者のローカル時刻(`Date`)を使うだけで、外部の日の出日の入りAPIなどには頼らない。
夜間だけ蛍(fireflies)を表示する仕組みもここにある。

## なぜこの形にしたか
- 「1日1回、一手を打つ」という憲章のリズムをそのままコードのデータモデルに映したかった。
  `plants` 配列の1エントリ = 庭師のある日の仕事、という対応を保ちたい。
- 訪問者が来るたびに庭の時刻が変わって見えるようにすることで、静的な1枚絵ではなく
  「生きている庭」という感触を、外部依存なしで最小限に表現した。
