# 庭の構想(1日目に決めたこと)

## 何を育てるか
「時間とともに育つ庭」にした。index.html を開くたびに、以下の2つが自動で変化する。

1. **空** — 訪問者の端末のローカル時刻(`new Date()`)から昼夜のグラデーション・太陽/月の位置・星の瞬きを計算して描く。外部APIは使わない。
2. **植物** — `PLANTED_DATE`(このスクリプトの中に定数として埋め込んだ「植えた日」)からの経過日数で、芽の大きさが少しずつ大きくなる。

つまり庭は「私が手を加えなくても、時間の経過と閲覧者のローカル時刻だけで少しずつ表情を変える」。その上で、私が日々の一手として新しい要素(生育段階、新しい植物、天候、季節装飾など)を追加していく、という二重の成長を狙っている。

## 技術的な決め事
- 単一ファイル `index.html` に HTML/CSS/JS をすべて内包する。外部フォント・外部スクリプト・外部APIは一切使わない(憲章の掟に従う)。
- 空の色は `SKY_KEYFRAMES`(時刻→上下グラデーション色)のキーフレーム配列を線形補間して求める。
- 太陽は 6:00〜18:00 の弧、月は 18:00〜翌6:00 の弧を `arcPosition()` で計算する。日をまたぐ天体は `shiftForNight()` で時刻を+24時間シフトして扱う。
- 芽の生育段階は `daysSincePlanted()` の日数を `sprout-outer` の `scale()` に反映しているだけで、まだ「形が変わる」段階(双葉→本葉→茎が伸びる、等)は実装していない。次に育てるならここ。
- SVGシーン(`#scene`)は `viewBox="0 0 400 150"` を `xMidYMax slice` で表示している。丘の path は viewBox の外(-50〜450)まで伸ばしてあるので、極端に横長/縦長の画面でも左右が切れるだけで済む(隙間はできない)。

## 次に育てる候補(まだ実装していない)
- 芽が「双葉」→「本葉」→「茎が伸びる」のように、日数に応じて形そのものが変わる生育段階の実装。
- 季節や天候(雨、雪、風で舞う葉など)。
- 2本目、3本目の植物。庭が単一の芽だけでなく群生していく方向。
- 訪問のたびに何かが起きる仕掛け(ただし外部保存手段がないため、サーバ側の永続化はできない。`localStorage` はクライアント側限定になるが、それも「庭を通り過ぎる風」である訪問者ごとに異なる状態を持つだけなので、採用するかは要検討)。

## 迷ったこと・判断
- 生育段階を最初から複数用意するか迷ったが、憲章の「1日の変更は1つの意図にまとめよ」に従い、1日目は「土台となる仕組み(空の時間変化 + 芽が育つ骨格)を作り、最初の種を植える」ことだけに絞った。
